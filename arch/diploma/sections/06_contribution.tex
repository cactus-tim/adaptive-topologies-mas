\section*{Авторский вклад}
\label{sec:contribution}
\addcontentsline{toc}{section}{Авторский вклад}

Авторский вклад настоящей работы сводится к~четырем результатам.

Первый~--- программная инфраструктура исследования. В~рамках работы
с~нуля разработан и опубликован под открытой лицензией MIT
мульти-агентный
фреймворк адаптивных топологий для мульти-агентных систем
(от англ. Adaptive Topologies for Multi-agent systems, ATM),
объединяющий пять статических коммуникационных топологий, адаптивную
мета-топологию второго уровня, конечный автомат фаз, маршрутизатор
фаз и~маршрутизатор топологий в~двух режимах (на~основе правил и~на~основе языковой модели),
защитные правила переключения, шлюз взаимодействия с~человеком
с~пятью ролями и~маршрутизатором ролей, подсистему
наблюдаемости с~двухкомпонентным хранилищем (реляционная база
PostgreSQL и колоночный формат Apache Parquet). Кодовая база
содержит 21~327~строк кода на~языке~Python, распределенных
по~112 программным модулям внутри тринадцати функциональных слоев.

Второй~--- формальная модель и таксономия метрик. Введена
формализация мульти-агентной системы как кортежа из шести
компонентов с~зависящей от~фазы коммуникационной структурой
(формулы~\ref{eq:meth:adaptive} и~\ref{eq:meth:thresholds}). Введена
таксономия из~пяти адаптивно-специфичных метрик~--- число
переключений топологии, доля заблокированных решений маршрутизатора,
стоимостный вклад маршрутизатора, доля регрессий качества и разрыв
до~оракула~(формула~\ref{eq:meth:delta-oracle}). Введена прокси-метрика
когнитивной нагрузки для запусков с симулятором
(формула~\ref{eq:meth:lcog}). Совокупность метрик позволяет
количественно характеризовать поведение динамически перестраиваемых
мульти-агентных систем и сопоставлять их по~единой шкале.

Третий~--- эмпирические результаты. Проведена воронка из~четырех
основных экспериментов и~двух кросс-семейных подтверждающих запусков
общим объемом~4230 завершенных запусков (\$$105{,}35$); для~каждого
исследовательского вопроса получен явный количественный ответ
(глава~\ref{sec:analysis}). RQ1 и~RQ3 подтверждены; RQ2 раскладывается на~центральный вывод~---
зависящее от~сложности задачи Парето-преимущество (Утверждение~1)~---
и~поддерживающее эмпирическое наблюдение об~инверсии Парето-победителя
маршрутизации между развернутыми конфигурациями работника
(Утверждение~2); RQ4 опровергнут с~интерпретацией
<<универсальный отрицательный результат>> (Утверждение~3). Все головные
эффекты сопровождены непараметрическими бутстрап-доверительными
интервалами; устойчиво исключают границу три из~них.

Четвертый, ключевой~--- методологический вывод. Главный
методологический результат работы~--- эмпирическая количественная
демонстрация ценности адаптивного дизайна на~нетривиальных
задачах. На~корпусах, где единичная статическая топология имеет
реальные ограничения (CommonGen, DABench), адаптивная мета-топология
дает Парето-выигрыш и~поведение наименьшего риска по~трем
независимым осям (наихудший случай качества, дисперсия качества,
разброс стоимости), а~также несет три структурных свойства дизайна
(единый конфиг развертывания на~разнородных корпусах, интеграция
HITL-сигнала в~маршрутизатор топологий, фазовое переключение
под-топологий). Результат подтвержден при~контролируемых условиях
одного семейства работника и~устойчив к~основным сценариям
конфаунда.

В~качестве дополнительного эмпирического наблюдения работа
фиксирует инверсию Парето-победителя маршрутизации между
развернутыми конфигурациями работника (gpt-oss-120b и~Qwen-3-235B),
мотивируя практику кросс-конфигурационной валидации настроек MAS
перед~переносом на~новую целевую конфигурацию. Механизм инверсии
(семейство весов, глубина рассуждений, поддержка структурированного
вывода) в~настоящей работе не~устанавливается и~оставлен открытым.

Универсальный отрицательный результат по~RQ4 дает конкретное
проектное ограничение~--- адаптивность на~двух уровнях
одновременно (топология и~роль) избыточна, достаточно одного
уровня (топологии); второй (роль) дает регрессию и~должен быть
исключен из~базового дизайна.
