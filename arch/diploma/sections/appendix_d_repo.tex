\section{Состав программного репозитория}
\label{app:repo}

В приложении приведено краткое описание состава программного
репозитория проекта. Состав фиксирован по состоянию идентификатора
фиксации, указанного в приложении~\ref{app:github}. Полный объем
кодовой базы охарактеризован в выводах
главы~\ref{sec:architecture}.

\subsection*{Корневая структура}

\begin{description}[leftmargin=*, style=nextline]
\item[\code{src/atm/}] Основной пакет фреймворка. Тринадцать
   функциональных слоев, перечисленных ниже. Это и есть программный
   продукт настоящей работы.
\item[\code{conf/}] Декларативная конфигурация экспериментов и
   компонентов в формате YAML. Группируется по типам
   конфигурируемых сущностей.
\item[\code{scripts/}] Самостоятельные скрипты обслуживания
   экспериментов и сборки производных артефактов.
\item[\code{notebooks/}] Шаблон Jupyter-ноутбука для аналитической
   постобработки результатов прогонов.
\item[\code{pyproject.toml}] Декларация пакета и зависимостей,
   точка входа \code{atm} для запуска командной строки фреймворка.
\item[\code{README.md}] Точка входа в документацию проекта,
   инструкция по сборке среды и запуску экспериментов.
\end{description}

\subsection*{Слои пакета \code{src/atm/}}

Каждый слой представлен отдельным подпакетом Python. Назначения
слоев подробно описаны в разделе~\ref{sec:arch:overview} и в
таблице~\ref{tab:arch:layers} главы~\ref{sec:architecture}.
Ниже приведено краткое сопоставление слоев с их основными
программными артефактами.

\begin{description}[leftmargin=*, style=nextline]
\item[\code{atm.core}] Контейнеры состояния и базовые типы.
   Ключевые элементы --- \code{AgentState}, \code{SharedState},
   \code{GraphState}, перечисления \code{Phase} и \code{HumanRole},
   модели сообщений.
\item[\code{atm.llm}] Оболочка над провайдерами языковых моделей,
   модель ценообразования, бюджетные ограничители, детерминированный
   \code{FakeLLM}, фабрика \code{build\_llm}.
\item[\code{atm.tools}] Реестр инструментов и обертка над
   Docker-песочницей для исполнения генерируемого кода.
\item[\code{atm.agents}] Базовый класс \code{Agent} и пять
   специализированных ролей (планировщик, исследователь,
   исполнитель, критик, дебатер), плюс координатор для иерархических
   и адаптивных топологий.
\item[\code{atm.topology}] Шесть реализаций топологий и общий
   протокол \code{Topology}. Каждая реализация --- самостоятельный
   модуль (\code{star.py}, \code{chain.py}, \code{mesh.py},
   \code{debate.py}, \code{hierarchical.py}, \code{adaptive.py}).
\item[\code{atm.phases}] Конечный автомат фаз, маршрутизатор
   топологий, защитные правила переключения, ворота передачи
   состояния.
\item[\code{atm.human}] Протокол \code{HumanGateway}, реализации
   симулированного и интерактивного шлюзов, маршрутизатор ролей,
   политика обработки тайм-аутов.
\item[\code{atm.storage}] Объектно-реляционное отображение, модели
   таблиц PostgreSQL, асинхронные сессии, писатель формата Parquet,
   обертка над чекпойнтером LangGraph, директория миграций
   \code{alembic/}.
\item[\code{atm.observability}] Перехватчик событий LangGraph,
   сериализация событий, обертки над логгером структурированных
   записей.
\item[\code{atm.tasks}] Загрузчики и оценщики четырех корпусов задач
   --- HumanEval, GSM8K, CommonGen, InfiAgent-DABench.
\item[\code{atm.evaluation}] Судья оценки качества на основе
   языковой модели, оракулы достоверности, агрегатор шкалы
   NASA-TLX.
\item[\code{atm.experiment}] Схемы конфигов на библиотеке
   Pydantic и загрузчик на библиотеке OmegaConf с поддержкой
   расширения по сетке параметров (грид-экспансии). Запускает
   одиночные и грид-эксперименты через командную строку
   \code{atm} на библиотеке Typer.
\item[\code{atm.analysis}] Загрузчики результатов из PostgreSQL и
   Parquet, агрегаторы метрик, генератор графиков, построитель
   оракула по схеме исключения по одному.
\end{description}

\subsection*{Конфигурационные файлы \code{conf/}}

Декларативная часть проекта разбита на тематические директории.

\begin{description}[leftmargin=*, style=nextline]
\item[\code{conf/experiments/}] Полные конфигурации основных
   экспериментов и сглаживающих прогонов --- E1, E2, E3, E4
   с подвариантами, конфигурации подтверждающих прогонов,
   служебные прогоны проверки работоспособности (от англ.
   smoke tests).
\item[\code{conf/agents/}] Системные подсказки и параметры для
   шести ролей агентов.
\item[\code{conf/topology/}] Параметры по умолчанию для каждой
   из шести топологий.
\item[\code{conf/human/}] Параметры шлюза взаимодействия с
   человеком, политики обработки тайм-аутов, системные подсказки
   симулятора.
\item[\code{conf/model/}] Параметры по умолчанию для каждой
   языковой модели --- температура, максимальный размер ответа,
   ключи провайдеров.
\item[\code{conf/task/}, \code{conf/tasks/}] Конфигурации
   загрузчиков корпусов задач и стратифицированных выборок.
\item[\code{conf/oracle/}] Конфигурации построения оракула по
   схеме исключения по одному.
\item[\code{conf/evaluation/}] Параметры судьи оценки и
   агрегаторов метрик.
\item[\code{conf/sandbox/}] Параметры Docker-песочницы для
   исполнения генерируемого кода и профиль системных вызовов.
\end{description}

Тематическая структура повторяет деление пакета \code{src/atm/},
что обеспечивает прямое соответствие между декларацией параметров
и потребляющим их кодом.

\subsection*{Скрипты и ноутбуки}

\begin{description}[leftmargin=*, style=nextline]
\item[\code{scripts/gen\_analysis\_notebook.py}] Генератор
   аналитического ноутбука из шаблона. Используется перед
   началом разбора результатов очередного эксперимента.
\item[\code{scripts/derive\_seccomp.py}] Сборка профиля системных
   вызовов для Docker-песочницы.
\item[\code{notebooks/analysis\_template.ipynb}] Шаблонный
   ноутбук с шестью секциями для постобработки и визуализации
   результатов прогона.
\end{description}
