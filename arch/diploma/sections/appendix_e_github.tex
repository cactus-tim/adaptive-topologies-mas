\section{Открытый исходный код}
\label{app:github}

В соответствии с пунктом 5.5 Правил подготовки и защиты
выпускных квалификационных работ образовательной программы
«Прикладной анализ данных и искусственный интеллект» полная
программная реализация настоящего исследования размещена в
открытом доступе. Среди допустимых методичкой платформ (GitHub,
GitLab, Bitbucket, Яндекс.Диск) выбран GitHub --- благодаря
наличию встроенного механизма версионирования с уникальными
хеш-идентификаторами коммитов, что обеспечивает однозначное
соответствие текста работы конкретному состоянию исходного кода,
поддержке стандартных открытых лицензий и широкой
распространенности платформы в академической и инженерной практике.

\begin{description}[leftmargin=2em, itemsep=0pt]
\item[\textbf{Адрес репозитория}]
   \url{https://github.com/cactus-tim/adaptive-topologies-mas}
\item[\textbf{Идентификатор фиксации}] коммит
   \code{058271a39a0e} (полный хеш ---
   \mbox{058271a39a0e4ecc0e3b47bd1d826c03fc33872b}) ветки
   \code{main} по состоянию на дату сдачи работы.
\item[\textbf{Лицензия}] исходный код распространяется по
   лицензии MIT (текст лицензии --- в файле \code{LICENSE}
   репозитория).
\item[\textbf{Сборка среды}] полная инструкция по установке
   зависимостей, развертыванию базы данных PostgreSQL и проверке
   корректности сборки приведена в файле \code{README.md}.
\item[\textbf{Воспроизведение результатов}] конфигурации
   экспериментов главы~\ref{sec:experiments} размещены в
   директории \code{conf/experiments/}. Запуск одиночного
   эксперимента~--- \code{atm run --config conf/experiments/e1.yaml};
   запуск грид-эксперимента~--- \code{atm grid --config
   conf/experiments/e1.yaml}.
\item[\textbf{Служебные артефакты}] кеши, журналы прогонов и
   временные файлы в репозиторий не включены; они генерируются
   локально в директориях \code{.cache/} и \code{runs/}, исключенных
   из контроля версий через \code{.gitignore}.
\end{description}
