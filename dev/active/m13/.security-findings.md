## Findings

### 1. Path Traversal Vulnerability in Parquet Loaders (HIGH)

**Files affected:**
- `src/atm/analysis/loaders.py:198` — `load_llm_calls_for_experiment()`
- `src/atm/analysis/loaders.py:251` — `load_topology_transitions()` (parquet path)
- `src/atm/analysis/loaders.py:354` — `load_phases()` (parquet path)

**Description:**
The `exp_id` parameter is used directly in path concatenation without UUID validation:
```python
exp_runs_dir = parquet_dir / "experiments" / exp_id / "runs"
```

An attacker can pass `exp_id="../../../etc/passwd"` to traverse outside the intended data root.

**Severity:** HIGH

**Risk:** Unauthorized file access beyond `parquet_dir/experiments/` boundary.

**Note:** The PG-based loaders (`load_experiment()`, `load_runs()`) validate `exp_id` as a valid UUID first (line 45, 87), so they are safe from this attack.

**Recommendation:** Add UUID validation for `exp_id` in all three parquet loaders before path operations:
```python
exp_uuid = uuid.UUID(exp_id) if not isinstance(exp_id, uuid.UUID) else exp_id
# Then use in path: parquet_dir / "experiments" / str(exp_uuid) / "runs"
```
