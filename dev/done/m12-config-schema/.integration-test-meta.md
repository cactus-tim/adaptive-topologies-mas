# Integration test metadata — m12-config-schema

The published contract of this block is:
1. Pydantic types `GridCfg` / `EstimateCfg` / `ExperimentConfig.grid` / `ExperimentConfig.estimate` (consumed by m12-grid-runner, m12-estimate-status-cli).
2. Loader API `load_grid_configs(path, overrides) -> list[ExperimentConfig]` (consumed by m12-grid-runner).
3. DB schema: `runs.replay_of` (self-FK SET NULL), `runs.host`, `runs.process_pid`, composite index `runs_exp_status_idx` (consumed by m12-resume-replay, m12-grid-runner).
