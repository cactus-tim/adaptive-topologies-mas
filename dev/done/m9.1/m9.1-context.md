## Decisions

### Decision: `extra: dict[str, Any] | None` вместо конкретных полей в HumanCfg
- What: опциональный `extra` dict вместо добавления `judge_mode`, `scope`, `activation_round` и т.д. как отдельных полей
- Rationale: backwards-compatible, минимальные изменения config.py, каждая топология читает свои ключи самостоятельно. Слабость: typos pass silently (GAP-2, advisory). Caller responsibility.

### Decision: sequential composite для Debate "both" mode
- What: `_both_judge_postprocess` — одна closure: (1) LLM-judge inline, (2) human gateway, (3) aggregate human > critic. Не parallel fan-out.
- Rationale: human latency >> LLM latency; parallelism не нужен; single-node closure проще, чем fan-in/fan-out с state merge; module-level `_judge_postprocess` остаётся untouched.

### Decision: sub_team mode — no interrupt() внутри subgraph
- What: Hierarchical `scope="sub_team"` использует только `adispatch_custom_event` + LLMSimulatedGateway (synchronous). CLIGateway внутри subgraph — known limitation M9.1.
- Rationale: Flagged risk M9 §10 (subgraph + checkpointer + interrupt). Subgraph-level interrupt-resume deferred to M9.2. WARNING docstring присутствует. Integration test explicitly validates callback propagation (row assertion from both subgraphs).

### Decision: advisory default для Adaptive HITL
- What: `human_advisor` node — advisory mode по умолчанию (не override). Override включается явно через `HumanCfg.extra["human_can_override_router"]=True`.
- Rationale: Adaptive — meta-routing топология; overriding её routing без явного opt-in создаёт риск unintended side effects. Advisory mode — безопасный default: HITL fires, row пишется, routing не меняется.

### Decision: widen decided_by Literal без alembic migration
- What: добавить `"human_override"` в Literal в обоих `TopologyDecision` и `TopologyTransition` в `src/atm/core/types.py`.
- Rationale: DB column `topology_transitions.decided_by` уже `String(24)`; строка `"human_override"` — 14 chars; fits without schema change. Confirmed: `0001_initial_business_schema.py:155` и `storage/models.py` используют `sa.String(24)`.

### Decision: `build_human_node_factory` используется только в Star; остальные — inline closures
- What: DRY helper используется только для Star (reviewer pattern). Mesh, Debate, Hierarchical, Adaptive используют собственные inline closures.
- Rationale: Mesh's `human_peer` использует inline closure (не helper) потому что broadcast_bus voting semantics + round-aware activation (читает `_mesh_dispatch_round` из signals, пишет DECISION в broadcast_bus) несовместимы с дефолтным `apply_decision` фабрики без нового overload. Миграция Mesh на helper отложена на будущий рефакторинг. Debate/Hierarchical/Adaptive — специфичная семантика (judge outbox write, subgraph scope, router override). Chain остаётся reference-implementation, не мигрирует на helper.

### Decision: `runs.human_role` пишется один раз в `_insert_run`
- What: значение известно до старта graph — `cfg.human.role.value` или `None`. Не обновляется в процессе run.
- Rationale: поле уже есть в модели с M3 (`storage/models.py:138`, `String(32), nullable=True`). Scope = per-run (одна роль на run).
